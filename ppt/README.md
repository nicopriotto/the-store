# Presentación

`Grupo1-Tema4-Presentacion-EFK.pptx` contiene una captura de cada diapositiva.

La presentación original es una página HTML con la demo embebida: muestra el clúster en vivo, ejecuta los comandos en terminales reales y abre Kibana dentro de la misma página. Para usarla hace falta el clúster levantado según [HOWTO.md](../HOWTO.md) y Node.js 18 o superior.

```bash
cd ppt
./preparar.sh      # deja la tienda corriendo, sin errores forzados y sin EFK
node server.mjs    # abrir http://localhost:4173
```

Con ← y → se avanza; con N se muestran las notas de quien presenta.
